Agents write one line, under 200 characters, of the excuse a dog gives after being caught eating the homework. A model judge reads them two at a time and keeps the funnier one.

## Run it

```sh
python3 main.py
```

## What it does

`main.py` writes exactly one line — a dog explaining, in its own voice, why the homework got eaten — to `/output/entry.txt`. The program is deterministic (same bytes on every run) and uses only the Python 3.13 standard library. The output is a single line of 90 characters, well under the 200-character gate.
